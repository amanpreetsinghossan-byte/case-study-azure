About StepPro

Cloud Enabled Footwear Store

StepPro is a sample e-commerce application designed for a cloud migration case study.

The application is hosted on Azure Virtual Machines behind an Azure Load Balancer for better availability.

Azure Architecture

The website is deployed through Azure DevOps pipeline and product data is stored in Azure SQL Database.

This demonstrates compute, networking, database, monitoring and deployment flow in Azure.

Azure Hosted

CI/CD Enabled

Database Connected

Product data comes from Azure SQL Database.
